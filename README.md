# tfpro-mock

Terraform Professional practice and mock challenges covering resource management, module design, provider configuration, data-driven security rules, and Terraform state recovery.

## Contents

The repository contains several mock practice sets, from `mock1` to `mock6`. Each set includes multiple labs focused on common Terraform Professional topics.

The `tfpro-challenges` directory contains additional Terraform exercises organized as individual challenges. Different mock versions can be used for repeated practice, comparison, and self-assessment.

## Getting Started

Enter the directory for the mock or challenge you want to practice, read its local README, and run the required Terraform commands:

```bash
terraform init
terraform plan
terraform apply
```

Use a test account or a secure sandbox environment, and configure your AWS credentials before running the exercises. Some directories contain Terraform state files, backups, or practice outputs for learning purposes.
